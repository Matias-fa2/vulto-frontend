# Vulto+ Front

```bash
npm install
npm run dev
```

Abre em http://localhost:5173. A API precisa estar rodando na 8000.

Tela das lojas: http://localhost:5173/?admin=1

Abas do admin: Clientes, Produtos, Estoque, Vendas, Relatório (faturamento) e Atendimento.
Pede login do funcionário (código ou senha) na primeira vez, depois fica salvo no navegador.
